# 🎬 Umar AI Video Studio

Automated AI Video Production Suite.

**Creator & Platform Owner:** Hafiz Muhammad Umar

## Features
- ⚡ High-Speed Video Rendering (60 FPS) with FFmpeg
- 🎙️ Multi-part Voiceover Stitcher & Audio Scrubber
- 💬 Word-by-Word Viral Subtitle Engine & Hormozi FX
- 🎬 Precision Multi-Track Visual Timeline (Media, Captions, Voice, Music)
- 🛠️ 1-Click Diagnostics & Self-Healing Cache Cleaner

## Run Locally
```bash
cd backend
pip install -r requirements.txt
python app.py
```
Then visit: `http://localhost:8000/app/`
